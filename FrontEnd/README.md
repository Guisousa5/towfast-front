# ReboqueFrontEnd

Pequena aplicação frontend para o projeto Reboque.

## Descrição

Este repositório contém a interface frontend mínima do projeto Reboque. É uma aplicação estática composta por HTML, CSS e JavaScript.

## Estrutura do projeto

- [index.html](index.html) — página principal
- [app.js](app.js) — código JavaScript
- [style.css](style.css) — estilos CSS

## Pré-requisitos

- Navegador moderno (Chrome, Firefox, Edge, etc.)
- (Opcional) Node.js para rodar um servidor local

## Executando localmente

Opções rápidas:

- Abra [index.html](index.html) diretamente no navegador.

- Ou rode um servidor local (recomendado para evitar problemas com CORS):

```bash
# usando http-server (recomendado via npx)
npx http-server -c-1

# ou usando Python 3
python -m http.server 8000
```

Depois acesse http://localhost:8080 (ou a porta exibida pelo servidor).
